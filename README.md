# NCR-Ride-Booking-Analysis
SQL and Power BI analysis of 150K+ NCR ride booking records

# Project Overview

Analyzed 150,000+ NCR ride booking records using MySQL to uncover insights into ride demand, revenue, cancellations, vehicle performance, customer ratings, and operational efficiency.

# Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- Power BI

# Key Metrics

| Metric | Value |
|---|---:|
| Total Bookings | 150,000 |
| Completed Rides | 93,000 |
| Completion Rate | 62% |
| Cancellation Rate | 25% |
| Total Revenue | ₹47.26M |
| Average Booking Value | ₹508.18 |
| Total Ride Distance | 2.42M |
| Average Customer Rating | 4.4 |

# SQL Analysis

The project covers:

- Data validation and NULL value analysis
- Duplicate booking ID analysis
- Booking status analysis
- Revenue and ride-distance analysis
- Vehicle type performance
- Pickup and drop location analysis
- Payment method analysis
- Customer and driver cancellation analysis
- Customer and driver rating analysis
- Peak-hour and date-wise booking trends

# Advanced SQL

Implemented advanced SQL techniques including:

- CTEs
- Subqueries
- CASE WHEN
- GROUP BY & Aggregations
- RANK()
- DENSE_RANK()
- ROW_NUMBER()
- LAG()
- Window Functions

# Key Insights

- 93,000 rides were successfully completed.
- Overall ride completion rate was 62%.
- Cancellation rate was 25%.
- Total revenue from completed rides was approximately ₹47.26M.
- Average customer rating was 4.4.
- Vehicle, location, time, and cancellation patterns were analyzed to identify operational trends.
